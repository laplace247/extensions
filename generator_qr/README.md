# Extensión Chrome - Generador QR

## Instalación

1. Abre Chrome → `chrome://extensions/`
2. Activa "Modo de desarrollador"
3. Clic "Cargar extensión sin empaquetar"
4. Selecciona carpeta `extensions`

## Generar iconos

1. Abre `create-icons.html` en navegador
2. Se descargan automáticamente en carpeta `img/`

## Uso

- Clic en icono extensión
- Ingresa texto/URL
- Personaliza colores y tamaño
- Descarga o comparte QR

## Archivos

- `manifest.json` - Configuración
- `popup.html/css/js` - Interfaz
- `qrcode.min.js` - Librería QR
- `share.svg` - Icono compartir
- `img/` - Iconos extensión
