# Extensión Chrome - Convertidor JFIF a PNG

## Instalación
1. Abre Chrome y ve a `chrome://extensions/`
2. Activa el "Modo de desarrollador"
3. Haz clic en "Cargar extensión sin empaquetar"
4. Selecciona la carpeta `extens02`

## Uso
1. Haz clic en el icono de la extensión
2. Selecciona archivos JFIF
3. Haz clic en "Convertir y Descargar"
4. Se descargará un archivo ZIP con las imágenes PNG

## Notas
- Necesitas agregar iconos (icon16.png, icon48.png, icon128.png) para completar la extensión
- La extensión funciona completamente offline
